# Point Gym Web Application

A lightweight, responsive multi-page web application designed for a fitness facility. This project focuses on UI layout techniques using modern CSS (Grid and Flexbox) and dynamic DOM manipulation using Vanilla JavaScript.

## Features

- **Multi-Page Structure:** Dedicated pages for Home, Coaches Directory, InBody Submissions, Contact, Pricing, and User Authentication.
- **Dynamic Layouts:** Built using CSS Grid and Flexbox for responsive elements across pages.
- **Interactive UI:** Dynamic mouse event handlers for buttons and navigational elements.
- **Form Validation:** Client-side form input validation implemented using JavaScript to ensure required user data entry.

## Tech Stack

- **HTML5:** Semantic site structure and accessibility.
- **CSS3:** Custom styling, Grid layout, Flexbox, and CSS state selectors.
- **JavaScript (ES6):** DOM selection, event handling, and form validations.
